Crie quizzes interativos em formato de funil para suas páginas de conversão.

== Description ==

O **Quiz Interativo** permite criar quizzes ramificados com visual atraente diretamente no seu painel WordPress.

**Recursos principais:**

* Editor visual sem código – crie páginas, opções e ações no painel
* Funil ramificado – cada opção pode ir para uma página diferente ou abrir uma URL
* Layout responsivo – funciona perfeitamente em celular, tablet e desktop
* Personalização total – cores, fontes, tamanhos, bordas, sombras
* Disclaimer e links de política em cada página
* Shortcode simples: `[quiz_interativo id="1"]`
* Performance otimizada – CSS/JS carregados somente onde o shortcode está presente
* SEO-friendly – markup semântico com roles ARIA e atributos de acessibilidade

== Installation ==

1. Faça upload da pasta `quiz-interativo` para `/wp-content/plugins/`
2. Ative o plugin em **Plugins > Plugins Instalados**
3. Acesse **Quiz Interativo** no menu lateral para criar seu primeiro quiz
4. Copie o shortcode gerado e cole em qualquer página ou post

== Frequently Asked Questions ==

= Como inserir o quiz em uma página? =
Após criar o quiz, copie o shortcode exibido (ex: `[quiz_interativo id="1"]`) e cole no editor da página.

= Posso ter múltiplas perguntas? =
Sim! Cada quiz pode ter quantas páginas quiser. Cada opção pode direcionar o usuário para qualquer página do quiz ou para uma URL externa.

= O quiz funciona no Elementor / Divi / Gutenberg? =
Sim. O shortcode funciona em qualquer builder que suporte shortcodes, incluindo um bloco de Shortcode do Gutenberg.
